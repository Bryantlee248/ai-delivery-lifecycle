# 治理等级与触发矩阵

## 四个等级
| 等级 | 适用 | 必需 | 不需要 |
|---|---|---|---|
| L0 探索/PoC | 合成数据、本地、可重建、无真实用户 | 五文件 + 最小校验 | 正式 SLO、复杂风险台账、多环境晋升、完整 SBOM |
| L1 协作开发 | 多 AI/开发者、共享代码、外部 API、CI | + Git 分支保护、CODEOWNERS、IWP、架构评审、契约、依赖锁定 | 生产级威胁模型、DR |
| L2 受控试点/预生产 | 真实但受限数据、共享环境、代表性用户、部署恢复 | + 环境/权限注册、数据目录、威胁模型、SBOM、SLO、备份恢复、制品晋升 | 生产批准逐次签署、灾备演练 |
| L3 生产/受监管 | 生产数据、业务 SLA、不可逆影响、合规审计 | + 人类逐次生产批准、HA/DR、制品签名、错误预算、事件复盘、退役 | — |

## 触发矩阵（只有触发才建对象，不预制空表）
| 触发事件 | 必须新增/启用 |
|---|---|
| 多个技术方案 | 决策/ADR |
| 实施方要求改架构 | RFC |
| 第二个 AI/开发者加入 | IWP + 文件所有权 + 评审协议 |
| 第一个外部 API/事件 | 契约 schema + 兼容规则 |
| 第一个持久化业务数据 | 数据目录、主权、迁移、保留 |
| 第一个共享环境 | 环境、权限、配置注册 |
| 第一次制品发布 | 制品清单、摘要、SBOM、发布记录 |
| 接触真实敏感数据 | 数据分类、威胁模型、审计、脱敏 |
| 进入预生产 | SLO、备份恢复、容量、漂移检测 |
| 进入生产 | 生产批准、错误预算、DR、事件、退役 |
| 出现规则偏差 | 例外记录 + 到期时间 |
| 出现未立即修复问题 | Finding/技术债台账 |

## 升级原则
- 等级**只能由风险事实触发**升级，不因「最佳实践列表很长」而升级。
- 退出高风险阶段后可归档活动台账，但**不删除历史证据**。
- `PROJECT.json` 的 `governance_level` 与实际对象一致性由 `validate-governance.mjs` 强制：L2 必须有 `environments`+`components`，L3 必须有 `risks`+`exceptions`；低等级建高等级对象会提示（过度治理）。
